# 79 - 2026-09-08 真实母标签收展与左到右实现

## 1. 最终交互模型

本轮删除全部虚拟聚合节点/聚合边方案。收展控制点是拥有大量叶子子标签的真实母节点。

- 母节点内部显示 `展开 N项` 或 `收起 N项`。
- 点击母节点正常选中，同时切换其自身高密度叶子分组。
- 不创建“其余对象”、分组标题、组框、关系节点或漂浮按钮。
- 每个母节点独立；状态按案件+母节点+关系+目标类型保存。

## 2. 折叠资格

仅折叠：当前母节点直接子标签、同关系/同类型、无任何真实出边、只有一个父节点、数量大于6。

以下永远默认展开：

- 有后续真实关系的子节点；
- 多父节点；
- 数量不超过阈值的普通分支。

收展数量只计算可折叠叶子，不包含能继续向后的子节点。

## 3. 左到右布局

- 所有可见实体按真实有向BFS最短深度确定x坐标；深度越大越向右。
- 同一母节点的子节点位于右侧下一层并纵向排列。
- 有下游的子节点优先排列，折叠叶子在后。
- 收展只增减叶子节点及对应真实边，不改变主链与更深层节点坐标。
- 无根可达对象仍进入未连接区，不制造边。

## 4. 保持不变

- 底层实体、关系方向、数量、属性不变。
- 普通节点单击、关系单击/双击、Option拖动、空白平移、滚轮缩放不变。
- 结构化属性、智能导入、左右栏和导出不变。
