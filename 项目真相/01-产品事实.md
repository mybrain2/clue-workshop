# 产品事实（当前）

> 更新至 0.7.7。当前全貌见 `00-AI接手总览.md`，完整复盘见 `43-全量产品与工程复盘.md`。

## 产品定位

线索研判是一个**本地优先、单案件隔离、手工录入关系结果**的 macOS 桌面工作台。它不负责替用户查询数据，而是把已经查到的账号、手机号、IP、设备、群聊、位置、机房、平台账号和组织等结果快速组织成可读关系图。

## 核心用户任务

```text
创建案件 + 首条线索
→ 选择图中当前对象
→ 一键添加关联结果（可一次粘贴多条）
→ 自动去重写入本地关系图
→ 通过路径 / 局部关系网 / 全量表阅读
→ 标记重点、状态和备注
→ 导出统一案件包，或在另一台安装同软件的设备中导入
```

## 已确认的产品约束

- 案件是绝对数据边界；同值对象不会跨案件自动合并。
- 底层是有向、多对多、可回连的图；调查路径仅是阅读投影，不能替代底层数据。
- 位置、机房是账号/IP 的附属背景事实，不是与账号同等级主线。
- 高频操作应少点击、输入优先；完整字段仅在需要时展开。
- 系统只能表达已录入事实及其人工关系，不自动推断身份或生成未经记录的结论。
- 本阶段没有在线服务、账户、多人协作、外部数据接入或跨案关联。

## 现有能力

- 案件创建、搜索、排序、归档文件夹、回收站和恢复。
- 12 类对象与状态、角色、备注、重点、关系强调。
- 快捷关联、多值粘贴、Excel/CSV 映射、截图 OCR 候选文本。
- 调查路径、局部一/两跳关系网、全量关系表、高连接聚合。
- 撤销/重做、案件包导入导出、CLI/MCP 受控自动化。

## 当前不应宣称支持

- 生产级证据保全、附件治理、静态加密、导入批次回滚。
- 跨案实体合并、协作权限、地图、时间线、自动查询。
- 基于真实案件的人工可读性验收；现有通过的是脱敏结构回归。

## 可验证成功标准

- 新建案件并输入第一条线索，不需要理解数据模型。
- 选中对象后可用明确的自然语言按钮录入下一跳关系。
- 同一批次多值写入会去重且不让高连接分支淹没主线。
- 用户点击节点或关系能立刻看见局部高亮反馈。
- 导出案件包可导入为新案件，不覆盖本地案件。
