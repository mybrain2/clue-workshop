# 完整关联入口与位置 / 机房信息

## 本轮确认

右侧“添加关联”不是只列当前类型的少数高频动作，而应当是**每个选中对象都能直接连接到完整的线索对象集合**。用户不应该因为当前节点是 QQ、微信、IP 或群聊而找不到位置、机房或其他所需对象。

## 交互规则

任一选中对象右侧均显示以下预设关联入口：

- 微信号
- QQ号
- 手机号
- IP
- 活跃位置
- 机房信息
- 同机设备
- 群聊
- 平台账号
- 团伙 / 组织
- 主体簇
- 自定义关联

预设按钮仍显示对象类型和默认扩散方式；默认扩散方式只减少填写步骤，用户仍可在保存前调整。

## 新对象类型

### 活跃位置

- 用于记录账号的活跃地区、城市、商圈、站点等人工查得结果。
- 示例：`广东 · 深圳`。
- 默认关系：`账号活跃位置`。
- 默认扩散方式：人工关联。
- 不自动推断地理坐标、行政区或同地关系；只记录用户填写的事实。

### 机房信息

- 用于记录 IP 所属的机房、云区域、IDC、网络出口等人工查得结果。
- 示例：`深圳 · 南山机房`。
- 默认关系：`IP 所属机房`。
- 默认扩散方式：同 IP 扩散。
- 机房是 IP 的环境属性，不等同于账号人员活动位置；两者在模型和显示上分开。

### 自定义对象

- 自定义表单要求：关联对象类型、关系名称、至少一个结果。
- 可用于域名、支付账号、车辆、订单号、邮箱、网站、收货点等当前未预设但有调查价值的对象。
- 同一案件内按“对象类型 + 值”复用节点，避免重复建点。
- 自定义关系默认人工关联，可选其他扩散方式，并支持推导备注。

## 显示调整

### 关系标签

关系标签需要识别关系，但不应比账号卡片抢眼：

- 高度由 24px 降为 20px；
- 默认文字降为 10px、使用次级文字色；
- 默认使用低对比边框和轻透底色；
- 只有重点关系或选中关系使用强调色和较强边框。

### 实体节点

账号、IP、位置、机房等对象卡片是画布主角：

- 普通节点提升至 132 × 46；
- 边界由 1px 提升到 1.25px；
- 主值文字提升为 12px / 650 字重；
- 类型色点增大；
- 重点节点仍使用手工颜色、左色条和轻填充。

对象类型色与人工重点色继续分层：类型色说明“是什么”，重点色说明“本案中值得优先看”。
