# 导入与案件注释融合方案

> 状态：调研完成，作为下一轮桌面实现规范。

## 用户问题

现有工作台需要补齐六类能力：

1. 节点颜色与类型指示一致，但保持低饱和；
2. 账号别名/命名与轻量备注；
3. 调查路径每一层的可编辑分栏标题；
4. 从截图、Excel、剪贴板纵列导入候选对象；
5. 案情简介、警方处置、当前现状三类案件级备注，并进入简报；
6. 账号备注可在图上轻量可见、详情中展开。

## 成熟项目与取舍

| 组件/项目 | 已核验机制 | 采用方式 | 不采用的部分 |
|---|---|---|---|
| PaddleOCR / PP-Structure | 本地 OCR、中文和版面/表格结构化、图像/PDF 输入 | 作为可选本地 OCR sidecar：截图 → 候选文本/列 → 人工预览确认 | 不让 OCR 直接写入案件；不把模型、Python 运行时硬塞进首个轻量安装包 |
| SheetJS CE | Apache-2.0；解析复杂 Excel/CSV 的成熟工具 | 桌面前端读取 `.xlsx/.xls/.csv`，抽取工作表、表头、列值 | GitHub 镜像停止更新，依赖官方新源/固定版本；不依赖其 Pro 功能 |
| OpenRefine | “预览 → 映射 → 清洗 → 确认 → 批次追溯”的成熟范式 | 借鉴导入预览、错误行、映射模板、批次回滚 UX | 不嵌入通用大工具；不暴露自由表达式清洗 |
| React Konva | MIT；复杂图形/批注编辑能力 | 未来用于更强的手动节点布局和局部注释编辑参考 | 当前 SVG 已满足路径阅读，暂不增加第二图引擎 |

## 一条统一导入管道

```text
剪贴板纵列 / Excel列 / 截图OCR
        ↓
候选值列表（不写库）
        ↓
选择“当前对象 + 对象类型 + 关系标签”
        ↓
规范化、去空、去重、格式提示
        ↓
预览：新增 / 复用 / 跳过数量
        ↓
确认后调用同一 add_relations 事务
        ↓
案件图、全量表、简报同步刷新；记录导入批次
```

OCR、Excel、纯文本只是在“候选值”产生阶段不同，后续不会分别维护关系写入逻辑。

## 导入 UX

### 1. 纵列粘贴（P0）

用户选择当前节点后点击“批量导入”，直接粘贴多行、Tab 分隔或逗号分隔内容；选择对象类型和关系。系统展示：

- 识别总数；
- 有效值数；
- 与当前案件已有对象重复的数；
- 预计新增关系数；
- 前 20 项预览。

### 2. Excel/CSV（P0）

- 选择本地 `.xlsx/.xls/.csv`；
- 显示工作表和前 20 行；
- 用户选择一个来源列，或选择“合并多列为一行”；
- 复用同一预览确认页；
- 保存来源文件名、工作表、列名、导入时间与批次摘要。

### 3. 截图 OCR（P1）

默认使用本地 OCR，不上传。PaddleOCR 是高质量中文/结构化表格候选；macOS 可先以本地 sidecar 形式执行。输出仅为候选文本和置信度：

- 识别到表格时可选列；
- 识别到纵列时逐行预览；
- 低置信度值标黄；
- 用户可修改、删除、合并；
- **确认前不入案件库**。

没有模型 sidecar 或模型未安装时，应用明确显示“截图 OCR 尚未安装”，并提供“复制识别文本粘贴导入”的降级路径，不假装已识别。

## 数据模型

### Case

- `background`：案情简介；
- `police_disposal`：警方处置；
- `current_status`：当前现状；
- `path_lanes`：JSON 数组，默认 `初始线索 / 联系方式 / 账号关系 / 设备与网络 / 社交与组织 / 延展`；
- `updated_at` 与操作历史。

### Entity

- `label`：不可变主值，例如 QQ 号、微信号、手机号；
- `display_name`：人工命名，例如“团伙联络号”“生活号 A”；
- `note`：为什么重要、如何推导、后续注意事项；
- `kind` 与低饱和类型色；
- 账号卡常驻仅显示类型 + 主值 + 可选命名，备注只以小点/展开详情呈现。

### ImportBatch（P0.5）

- 来源类型：paste / spreadsheet / screenshot_ocr；
- 来源名称和文件哈希；
- 工作表/列；
- 原始候选数、有效数、复用数、新增数、跳过数；
- 导入规则、操作者时间、可回滚快照。

## 视觉与阅读规则

- 类型色只用于节点小圆点、细边和约 4–8% 的轻填充；不要给整张卡用重色；
- 节点第一行：`QQ号 · 123456789`，第二行在有命名时显示别名；
- 有备注节点出现很小的说明标记，悬浮/选中后展示摘要；
- 路径顶部按层显示可编辑分栏，不依赖具体实体类型，避免把手机号或 IP 强塞到不正确的栏目；
- 报告按照案情简介、警方处置、当前现状、初始线索、核心链路、待展开分支输出。

## 实施顺序

1. 案件三段备注、路径分栏、账号命名与卡片视觉；
2. 粘贴/Excel 列导入预览和批量关系写入；
3. 导入批次和批次回滚；
4. PaddleOCR 本地 sidecar、截图候选预览；
5. 与导入结构同构的 SVG/PNG/XMind/XLSX/casepack 导出。
