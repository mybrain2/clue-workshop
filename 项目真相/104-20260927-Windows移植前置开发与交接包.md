# 104 - 2026-09-27 Windows 移植前置开发与交接包

## 背景与策略

用户规划 Windows 版开发。约束：开发账号都在 Mac、Windows 侧 AI 能力弱且 token 少。策略定为 **"Mac 做完 99%，Windows AI 只做照单执行"**——本机完成全部跨平台代码、配置、脚本、文档，Windows AI 只负责环境搭建+编译+打包+验证。

## 前置审计结论（平台耦合面比预想小）

全代码审计后确认耦合点仅 5 处：
1. `case_core.rs` `data_root()` 硬编码 macOS 路径
2. `main.rs` 剪贴板用 `/usr/bin/pbpaste`（已有 cfg 兜底）
3. `case_core.rs` `xmind_sidecar_dir()` 找 `node` 二进制（macOS arm64 Mach-O）
4. CLI `app-open` 硬编码 `/Applications/线索研判.app`
5. `tauri.conf.json` bundle 只有 mac targets

其余天然跨平台：前端零平台引用、GB18030 解码已内置、icon.ico 已存在、无 macOS 专属 crate、SQLite/.cluecase/附件格式全部跨平台、zip 条目名强制正斜杠。

## 已完成的开发（本机做完的部分）

### cfg(windows) 改造（4 文件 + 1 脚本）

- `data_root()`：三分支 macOS(HOME/Library)/Windows(APPDATA)/Linux(XDG)；Windows 数据目录 `%APPDATA%\线索研判数据`
- 剪贴板：Windows 用 PowerShell `Get-Clipboard -Raw`，UTF-8→UTF-16LE 双解码兜底；imports 加 cfg 守卫
- xmind sidecar：`node.exe` 按平台命名；探测增加 `<安装目录>\resources\xmind`
- CLI app-open：Windows 用 `cmd /C start`，默认路径 `%LOCALAPPDATA%\线索研判\线索研判.exe`
- `prepare-xmind.mjs`：win32 下复制为 `node.exe`
- `tauri.conf.json`：targets 加 `nsis`；`windows.webviewInstallMode=embedBootstrapper`；`nsis.installMode=currentUser`（注意：值是 currentUser 不是 perUser，交叉检查抓过这个错）、简中语言包
