# 桌面体验回归与布局审计

> 日期：2026-09-02。基线：macOS 0.5.2 候选构建；脱敏多跳案件与“桌面同步体验验收”案件。

## 本轮结论

桌面端可以稳定启动、读取本地案件库，并在 CLI/MCP 写入后刷新案件列表。此前截图中的“没有案件”不是 SQLite 数据缺失：运行日志显示当前程序启动后依次完成 `initialize_storage` 与 `list_cases`，读取到 8 个案件。

同时发现 macOS 曾弹出“线索研判意外退出”。崩溃报告指向的是已废弃的 `线索研判-manual-unverified.app`，而不是当前 bundle；该历史包与现行包使用相同 bundle identifier，导致按应用名称启动时可能命中旧包。后续测试和交付均只使用明确路径的当前 bundle，不能用旧手工包或按模糊应用名启动。

## 布局与交互审计

### 发现的问题与修复

1. **旧视图状态把画布保持在 55% 总览缩放**  
   画面像电路图，用户打开案件不能直接阅读。现以 `layoutVersion` 迁移旧本地视图状态；旧状态自动回到 100% 阅读比例。用户之后主动选择总览仍会保存。

2. **高连接群聊和手机号分支形成线团**  
   原实现按总节点数量硬截断，没有表达“还有哪些没展开”。现改为按父节点/关系类型折叠：默认保留 3 个代表节点并生成可点击的“折叠分支 / N”节点；顶部提供“展开 N 项 / 折叠大分支”。

3. **重复关系标签压住连线**  
   同一父节点下相同关系只保留一枚标签；选中、重点或聚合关系仍显示标签。这样保留关系语义，同时减少平行边的重复文案。

4. **右侧快捷关联不完整，按钮也不保证填入对应类型**  
   原来只显示前 8 种对象，且点击“添加QQ号”等按钮会进入没有预选类型的通用表单。现已列出微信、QQ、手机号、IP、位置、机房、设备、群聊、平台账号、组织、主体簇和自定义对象；每个按钮会预选对象类型并填入对应关系名称，仍允许手工修改。

5. **导出目录丢失中文案件名**  
   原来只保留 ASCII 字符，中文名全部变成下划线。现使用 Unicode 字母数字规则保留中文案件名。

## 当前限制

- 当前原生窗口自动化仅有屏幕截图权限，尚未取得 Accessibility 权限，无法稳定模拟鼠标/键盘点选或关闭系统弹窗；因此原生窗口的视觉审计以截图和运行日志为证据，复杂点击流继续由 CLI/MCP 端到端回归覆盖。
- SVG 导出仍为基础图谱导出，尚未与画布的折叠布局完全同构；XMind / PNG / XLSX / casepack 仍属后续 P0 项目。
- 当前图谱画布仍需要真实脱敏案件的人工阅读反馈，以校准折叠阈值和每支保留数量。
