# 53 - 2026-09-04 信息看板视觉系统与首个切片

## 1. 方向纠正

“懒人产品”指操作简单，不代表信息贫乏或界面简陋。线索研判是信息看板：必须保留对象身份、分类、原始值、状态、角色、重点和关系上下文，但要通过成熟的信息层级与设计系统降低理解成本。

明确禁止：

- 通用白卡 + 等权三行文字的 AI 模板感。
- 用中点 `·` 把不同语义混成同一种文案。
- 为了解释设计而把“主显示名、仅在可读级显示”等设计注释放进最终 UI。
- 依赖渐变、夸张圆角、彩色 pills、装饰箭头制造高级感。
- 视觉改动顺带改变图谱坐标、边、关系、选择、拖动、导出或数据逻辑。

## 3. 首个低风险视觉切片

本轮只修改 `GraphPanel` 节点内部信息排版和对应 CSS：

- 不改变节点坐标和 `164×62` 外框。
- 不改变边、关系标签、附属卡位置、布局算法、XMind、数据和交互。
- 保留类型色边框、状态虚线、重点琥珀外圈/角标、用户 accent、选中和一跳高亮。

节点信息改为三层：

1. Identity：13px / 600 主标题，最多两行。
2. Classification：类型与原始值分开呈现，不再混成同一中点字符串。
3. Status：状态、角色、重点形成底部紧凑状态行。

对缺少 `displayName`、`role`、`status`、`label` 的历史数据提供安全降级；长中文、长 ID 和角色均省略，不允许溢出。
