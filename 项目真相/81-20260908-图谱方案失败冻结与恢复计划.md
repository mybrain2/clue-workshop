# 81 - 2026-09-08 图谱方案失败冻结与恢复计划

## 结论

当前“真实母节点收展 + 有向BFS”方案冻结，不再继续修补。虽然单元测试通过，但真实截图证明视觉和交互不成立。

## 截图暴露的问题

- 母节点下存在无意义垂直残线。
- 分支节点与主链层级混杂，长斜线和交叉线影响阅读。
- 收展状态塞入普通节点，选中与收展共用一次点击，语义冲突。
- 折叠只过滤渲染对象，隐藏节点仍参与布局，造成大片空白和错误画布高度。
- 单向BFS把业务关系方向当作阅读层级，反向/多父关系被错误放入未连接区或产生长交叉边。
- 测试仅验证数量与x递增，没有验证最终坐标、边交叉、折叠后重排、裁切和真实点击。

## 冻结边界

- 停止修改当前GraphPanel布局、聚合和收展代码。
- 停止以“测试全绿”作为视觉验收结论。
- 不再新增母标签、虚拟节点、组框、分组容器或排序启发式。
- 结构化属性、智能导入和底层关系暂不回退。

## 恢复计划

1. 从0.7.9/0.7.12稳定发布产物或外部版本库提取可运行GraphPanel源码/CSS；不在当前失败布局上继续叠补丁。
2. 用固定QA案件建立基线截图：折叠态、展开态、主体关系网、全量关系表。
3. 重新定义收展：选择与收展分离、组级独立控制、折叠后重新布局、阅读方向不等于业务边方向。
4. 新布局先做纯数据→坐标快照测试和静态SVG，不接真实App。
5. 达到无重叠、边交叉阈值、视口完整、折叠重排后，再接入GraphPanel。
6. 真机手动点击通过后才更新桌面发布包。

## 进程状态

已关闭本项目全部Workbench、Vite、Tauri Dev、Cargo Run及发布进程，不保留空转进程。
