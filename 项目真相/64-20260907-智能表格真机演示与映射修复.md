## 1. 演示准备

在会话临时目录生成了四份仅用于演示的模拟表格：群列表、好友列表、QQ同机、QQ绑定手机号。账号为模拟值，不使用用户真实数据。

## 2. 启动修复

直接 `cargo run` 只能启动空白 Tauri 壳，因为开发配置依赖 Vite；`npm run tauri dev` 又因 GUI/CLI 双 binary 未指定默认程序而失败。已在 `src-tauri/Cargo.toml` 增加 `default-run = "clue-workbench"`，现在标准 `npm run tauri dev` 可启动完整 Workbench。

## 3. 真机发现并修复的问题

首次粘贴群列表演示数据时，程序识别为QQ群列表，但 `QQ账号(解密)` 与 `QQ群账号(解密)` 被表头别名冲突吞掉，导致三行均报缺少来源主键。

已修复：

- 群列表精确区分来源 `QQ账号(解密)` 与目标 `QQ群账号(解密)`。
- 好友列表区分 `查询账号(解密)` 与 `QQ账号(解密)`。
- 绑定表区分 `QQ账号(解密)` 与手机号。
- 解密列优先，普通列只作 fallback；一列不能同时映射两个端点。
