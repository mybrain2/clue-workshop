# 桌面版功能等价验收矩阵

> 目的：防止再出现“桌面外壳完成，但核心案件工作台未迁移”的误判。

## 基线定义

**网页 `demo/index.html` 是当前桌面迁移的唯一体验基线。**

桌面端可以在此基础上增加 SQLite、归档、回收站、原生文件和备份，但不得删除、替换或静态模拟以下核心能力。

## 验收矩阵

| 编号 | 能力 | 网页基线 | 桌面实现位置 | 验收方法 | 状态 |
|---|---|---|---|---|---|
| E-01 | 案件背景+种子线索 | 新建时选择起点类型和值 | `features/cases` + SQLite transaction | 创建后立即出现主体簇、起点与初始关系 | 未迁移 |
| E-02 | 真实节点/关系数据 | 每案内多对多图 | SQLite `entities` / `relations` | 数据库、路径、关系网、表格数量一致 | 部分骨架 |
| E-03 | 调查路径 | 有向分层树、主链/回连区分 | `features/graph/PathView` | 同样例输出同层级和节点 | 未迁移 |
| E-04 | 主体关系网 | 一跳默认、两跳按需 | `features/graph/NetworkView` | 选任意对象可切换一跳/两跳 | 未迁移 |
| E-05 | 全量关系表 | 同源关系数据表 | `features/graph/RelationTable` | 图中关系均可在表中检索 | 未迁移 |
| E-06 | 画布操控 | 缩放、平移、拖动、阅读、总览 | `features/graph/CanvasController` | 刷新后恢复每案视图状态 | 未迁移 |
| E-07 | 关联字典 | 全预设类型 + 自定义关联 | `features/relations/QuickAdd` | 任意对象可选预设或自定义类型 | 未迁移 |
| E-08 | 批量录入 | 逗号/中文逗号/换行、去重 | `features/relations/BulkInput` | 重复值不重复建节点，关系即时刷新 | 未迁移 |
| E-09 | 节点语义 | 状态、角色、备注、重点颜色 | `features/entities/Inspector` | 更新后路径、网、表与导出同步 | 未迁移 |
| E-10 | 关系语义 | 状态、扩散方式、推导、加粗 | `features/relations/Inspector` | 点击线/关系列表可修改且持久化 | 未迁移 |
| E-11 | 聚合展开 | 高度分支聚合、点击展开 | `features/graph/Aggregation` | 大分支不炸图，表保留全量 | 未迁移 |
| E-12 | 撤销/重做 | 当前案操作栈 | `features/history` + SQLite snapshots | 节点/关系编辑可撤销、重做 | 未迁移 |
| E-13 | 一段话概括 | 规则模板且只引用已录入事实 | `features/export/Summary` | 文本与快照关系一致 | 未迁移 |
| E-14 | 真实脑图导出 | 当前路径投影导出 | `features/export/GraphExport` | SVG/PNG不是固定样例，内容可对照数据库 | 未迁移 |
| E-15 | 案件管理增强 | 桌面新增 | `features/cases` | 右键归档/回收站/手动删除/排序可用 | 部分完成 |
| E-16 | 独立数据目录 | 桌面新增 | Rust storage | 数据与安装包分离 | 已验证 |

## 迁移规则

1. 先迁 `E-01` 至 `E-14`，再把 `E-15` 的 UI 与完整工作台融合。
2. 不使用固定样例节点、假按钮、固定 SVG 或硬编码摘要作为交付替代品。
3. 每完成一项，必须同时验证：
   - SQLite 数据；
   - 当前案件画布；
   - 全量关系表；
   - 应用重启后的持久化；
   - 导出快照。
4. 任一关键项未完成时，版本说明只能写“桌面基础设施预览”，不能写“桌面版可用”。

## 当前版本命名

当前 `0.1.0` 应标记为：

```text
macOS 桌面基础设施预览
```

不是正式 P0，不是网页功能等价版本。
