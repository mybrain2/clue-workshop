# 56 - 2026-09-04 节点颜色与外框语义收敛

## 用户问题

- 长标题超出节点。
- 顶部类型色边观感不佳。
- 同一节点叠加不同外框，不清楚每层含义，视觉混乱。

## 最终规则

- 删除顶部类型 keyline 与整圈类型色。
- 对象类型或用户自定义 accent 仅通过标题区域左侧 `7px` 低饱和实心色点表达；accent 优先。
- 普通节点只保留统一 `1px` 冷灰基础边框。
- 外框只表达交互：选中为 system blue `2px`，一跳为柔和绿色 `1.5px`，两者互斥。
- 重点不再使用额外琥珀外圈，只保留琥珀角标和底部“重点”文字。
- 待核实、已失效、已排除不再使用彩色/虚线外框，只在卡片内显示状态点和短文本。
- 节点固定三行：类型+状态 / 主标题 / 原始值或角色+重点。
- 主标题单行省略，按 SVG 可用宽度计算；完整内容保留在 `<title>` 中。
- context 节点保持原位置和尺寸，颜色同样只使用小色点。

- 左右栏、边、布局、附属标签、筛选、XMind、数据与交互均未修改。
