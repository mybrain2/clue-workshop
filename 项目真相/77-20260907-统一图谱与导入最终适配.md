# 77 - 2026-09-07 统一图谱与导入最终适配

## 1. 设计合同落地

- 调查路径使用真实有向BFS最短深度持续向右；有下游节点形成连续主链。
- 只折叠单父、无下游的同类叶子旁支；多父对象只显示一次并保留全部真实入边。
- path保留1个代表叶子，network保留3个；`其余对象 +N`只表示隐藏叶子。
- 聚合代理不作为路径起点，不入数据库/统计；展开后消失，顶部按钮恢复折叠。
- 位置/机房保留原附属背景卡例外，紧贴来源节点，不参与横向主链。

## 2. 标签与属性

- QQ/微信/平台账号/群聊存在昵称或显示名时，节点正面仍显示原始账号/群号。
- 节点最多显示两个关键属性；完整属性在右侧详情。
- 搜索覆盖对象/关系属性中文名和值；命中关系时显示关系和两端对象。
- 类型筛选覆盖全部12类。
- 单击关系右侧显示完整属性并可复制；关系表显示关键属性和可展开全部。
- 同机关系在选中/悬停时可显示一个相似度短摘要，其他关系不堆属性。
- 对象/关系编辑支持修改和删除已有内置属性。

## 3. 粘贴解析与计数

- 全量粘贴使用RFC4180/TSV引号感知解析。
- 支持CRLF/LF、引号内换行/Tab/逗号、双引号转义；未闭合引号明确报起始物理行。
- 分隔符按逻辑记录列宽一致性判断。
- 摘要区分物理行、逻辑记录、数据记录、有效/错误、唯一对象/关系、空行与重复表头。
- 9行4个唯一关系必须显示为9个有效行、4个唯一关系，而不是“只识别4行”。

## 4. 兼容与稳定性

- 旧空属性不显示占位且不崩。
- 无根有向可达对象放入未连接区，不伪装成根一跳。
- network不折叠多父叶子。
- 位置/机房附属卡、节点点击、关系单击/双击、Option拖动、平移缩放合同保持。

- 前端57/57通过。
- Rust20/20通过。
- npm build、cargo check通过。
- 真机唯一最新版正常启动，无错误边界、组框或纵向假链；主链按深度向右，标签显示账号和关键属性。
