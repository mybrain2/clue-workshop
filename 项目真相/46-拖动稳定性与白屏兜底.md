# 46 - 拖动稳定性与白屏兜底（0.7.11）

## 现象与根因

普通节点按下会立即进入拖动状态，短按、轻微鼠标移动、SVG 指针捕获与画布事件交织，导致点击被吞掉并可能进入不稳定指针路径。此前前端没有错误边界，任何渲染异常都会表现为白屏。

## 修复

### 交互分离

- 普通鼠标按下/点击节点只负责选中，不再启动节点拖动。
- 节点微调改为 **按住 Option（⌥）+ 拖动**；仅允许纵向、最大 ±96px、12px 吸附。
- Option 拖动使用 try/catch 包裹 SVG 指针捕获；捕获失败会安全取消拖动状态。
- 指针结束或取消都会清理拖动引用，避免状态残留。
- 位置/机房附属卡仍只能点击，不能独立拖动。

### 白屏兜底

- 根渲染入口新增 `DesktopErrorBoundary`。
- 如果后续发生未捕获的 React 渲染异常，界面显示“当前数据没有被修改”的恢复页与“重新加载界面”按钮，而非空白窗口。
- 错误会写入开发者控制台，方便后续复现和定位。

## 使用说明

- 点击节点：选中并显示局部高亮。
- 空白处左键：平移画布。
- Option（⌥）+ 拖动节点：上下微调节点位置。
- 关系单击：高亮；双击：编辑。
