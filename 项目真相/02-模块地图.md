# 模块地图（当前代码）

> 更新至 0.7.7。本文只描述已落地模块；计划项见 `43-全量产品与工程复盘.md`。

## 运行结构

```text
React 工作台
  ├─ App.tsx：案件加载、键盘操作、对话框、右侧操作区、状态同步
  ├─ cases/：案件库、创建、概览、归档/回收站
  ├─ graph/：路径、关系网、全量表、快速关联、节点/关系编辑触发
  ├─ import/：文本、表格、截图 OCR 候选导入
  ├─ export/：案件材料导出、案件包导入
  └─ lib/：跨端类型与 Tauri command 客户端
       ↓ invoke
Tauri command 薄桥（main.rs）
       ↓
case_core.rs
  ├─ SQLite schema/migration
  ├─ 案件、实体、关系、快照和撤销操作
  ├─ 归档/回收站
  ├─ 导出和案件包导入
  └─ revision 更新
       ↑
CLI / stdio MCP（共用 case_core）
```

## 前端模块与修改入口

| 模块 | 文件 | 责任 | 修改注意 |
| --- | --- | --- | --- |
| 工作台编排 | `src/App.tsx` | 初始化、案件切换、全局快捷键、对话框、右侧快捷卡 | 当前文件职责偏多；改操作后确认输入控件不触发全局快捷键 |
| 案件库 | `features/cases/CaseSidebar.tsx` | 搜索后显示、排序、归档文件夹、回收站和右键菜单 | 案件状态只允许 active/archived/trash |
| 创建案件 | `features/cases/CreateCaseDialog.tsx` | 标题、首条线索、类型识别 | 空值不应误高亮任何类型 |
| 图谱 | `features/graph/GraphPanel.tsx` | 三视图投影、布局、聚合、缩放/平移、选中高亮、删除/有限拖动 | 不能破坏图不是树、附属卡、聚合及原生非被动滚轮规则 |
| 快捷录入 | `features/graph/QuickAddDialog.tsx` | 预置类型、关系标签、多值输入、低频字段折叠 | 高频入口不应出现二次类型选择 |
| 批量导入 | `features/import/ImportDialog.tsx` | 文本、Excel/CSV、截图候选 | 确认前不得写库；目前缺 batch 审计与回滚 |
| 导出 | `features/export/ExportPanel.tsx` | 导出位置、材料路径、案件包导入入口 | 输出格式由 Rust 核心生成 |
| 类型桥接 | `lib/types.ts`、`lib/desktop-api.ts` | 跨端 schema、invoke 封装 | 改 Rust 入/出参必须同步更新 |
| 样式 | `styles/app.css` | token、布局、图、录入与弹窗 | 历史规则会覆盖；用最终计算样式验证 |

## 后端模块与数据边界

| 模块 | 文件 | 责任 |
| --- | --- | --- |
| Tauri 桥 | `src-tauri/src/main.rs` | 权限内命令、存储目录初始化、本地 OCR helper、运行日志 |
| 领域与存储核心 | `src-tauri/src/case_core.rs` | schema migration、去重、快照、撤销/重做、案件包、导出、revision |
| CLI | `src-tauri/src/bin/clue-workbench-cli.rs` | 机器可读 JSON 命令；不得实现第二套业务逻辑 |
| MCP | `integrations/mcp/clue_workbench_mcp.py` | stdio JSON-RPC 到 CLI 的受控映射；不开放永久删除 |

## 同源视图

- **调查路径**：默认阅读视图。账号与关联条件为主线；位置/机房紧贴来源对象；密集叶子聚合。
- **主体关系网**：围绕当前对象的一跳/两跳局部检查，不是第二条案件主线。
- **全量关系表**：同一关系数据的行式阅读；关系、状态和两端对象可见。

## 关键依赖关系

```text
案件状态/根节点 ─┐
实体、关系、快照 ├─ case_core ─ Tauri / CLI / MCP
导入/快捷录入 ───┘
case_core 返回 CaseDetail ─ GraphPanel / 表格 / 导出
revision ─ App polling ─ CLI/MCP 写入后桌面刷新
```
