# 00 - AI 接手总览

> 本文是后续 AI 接手本项目的首读文件。以当前代码和已验证发布版为准；编号较早的迭代文档用于追溯，不可覆盖本文的当前事实。

## 1. 产品与边界

**线索研判**是 macOS 本地优先的单案件关系工作台。用户把已经查到的账号、手机号、IP、设备、群聊、位置、机房、平台账号和组织等结果手工录入；系统保存为有向关系图，并投影为调查路径、局部关系网、全量关系表与案件材料。

当前边界：

- 一案件一工作区；跨案件不自动合并同值对象。
- 不接外部数据源，不做自动查询，不依赖 Obsidian 或 ClueProbe。
- 不把实体同值自动判为同一人/同一主体；去重只复用同一案件内的“类型 + 值”节点。
- 所有结论只来自已录入的数据，导出不得补写未记录事实。

## 4. 技术结构

```text
app/
├── src/                         React + TypeScript 前端
│   ├── App.tsx                  工作台编排、键盘操作、Tauri 调用、右侧快捷录入
│   ├── features/cases/          案件库、归档、创建、概览
│   ├── features/graph/          GraphPanel、快捷添加、关系投影与布局
│   ├── features/import/         文本/表格/截图导入
│   ├── features/export/         材料导出与案件包导入入口
│   ├── lib/types.ts             跨端类型与对象种类
│   └── lib/desktop-api.ts       唯一 Tauri invoke 桥接
├── src-tauri/
│   ├── src/case_core.rs         SQLite schema、业务核心、导入导出、快照
│   ├── src/main.rs              Tauri command 薄桥与本地 OCR 调用
│   └── src/bin/clue-workbench-cli.rs  CLI 薄桥
├── integrations/mcp/            stdio MCP，调用发布/构建 CLI
├── scripts_validate_*.py        回归脚本
└── release/macOS/               发布产物，不是源代码
```

架构决策：**Tauri v2 + React/TypeScript + Rust + SQLite，本地优先单体**。不存在 HTTP 服务、账号、认证或云同步；桌面端通过 `workbench_meta.revision` 每两秒轮询本地 CLI/MCP 的外部写入。

## 5. 数据事实

数据根目录是：

```text
~/Library/Application Support/线索研判数据/
├── casework.sqlite3
├── attachments/
├── exports/
├── backups/
├── snapshots/
└── logs/desktop-runtime.log
```

权威表：`cases`、`entities`、`relations`、`case_operations`、`case_snapshots`、`case_redos`、`workbench_meta`。

- `entities`：`kind`、`label`、`display_name`、`status`、`role`、`note`、`accent`、`pinned`、`custom_type`。
- `relations`：`source_id`、`target_id`、`label`、`spread`、`status`、`note`、`emphasis`。
- `cases`：案件三段说明、`archive_folder`、`root_id`、排序及状态。

禁止直接修改用户 SQLite；要通过 `case_core.rs`、Tauri command、CLI 或 MCP 进入，保持快照、revision 和审计操作一致。

## 6. 图谱与视觉的不可破坏约束

1. 底层是图，不是树；调查路径只是阅读投影。
2. 位置/机房是来源对象的附属背景事实：紧贴主卡下方，线从主卡底边到附属卡顶边，无箭头、无边标签。
3. 高连接叶子分支要聚合，不能回退为标签云或完整散点墙。
4. 选中必须有可见局部反馈：节点单击后以蓝色强焦点高亮自身、绿色次焦点高亮一跳对象并加粗相关边；关系单击后只高亮该线与两端，双击才编辑。其他节点和关系保持原样，禁止全图弱化或灰化。
5. 普通节点点击必须直接进入选中回调；节点只有按住 Option（⌥）再拖动时才能有限纵向微调，不得自由拖成手工绘图。
6. 画布滚轮只缩放，空白处左键才平移。缩放事件必须用原生 `passive:false` 监听器，缩放/平移用同一 `viewport` 状态原子更新。
7. 右侧直接录入密度以左侧案件栏为基准，不得恢复为大号营销卡片。

## 8. 接手顺序

1. 阅读本文、`42-AI协作与工程验收.md`、`43-全量产品与工程复盘.md`、`48-增量交接补充说明.md`。
2. 阅读 `src/lib/types.ts`、`src/lib/desktop-api.ts`、`src-tauri/src/case_core.rs`，以及 `src/features/graph/GraphPanel.tsx`、`src/main.tsx`。
3. 若改交互，先用实际运行界面/计算样式确认现状，不要只看 CSS 源码。
4. 小步修改后至少运行前端构建和 Rust 检查；图/存储/自动化改动还要运行两条 Python 回归。
5. 更新本目录的当前事实、变更日志、overview 与当日工作日志，再交付发布包。
