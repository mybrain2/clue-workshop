# 60 - 2026-09-04 归档文件夹与聚合标签收展

## 1. 需求边界

本次只处理：

1. 归档文件夹可以新建、重命名、删除空文件夹，并在归档案件时选择目标文件夹。
2. 图谱自动收纳的大关联分组可以逐组点击展开，再点击收起；不是普通关系标签，也不是归档侧栏折叠。

## 2. 归档文件夹

- 新增 `archive_folders` 表和 `cases.archive_folder_id`；保留旧 `archive_folder` 字符串兼容。
- 启动迁移会把旧归档字符串去重为文件夹并回填 ID，迁移幂等。
- 新增文件夹查询、新建、重命名、删除命令。
- 重命名事务同步关联案件的兼容名称。
- 只允许删除空文件夹；非空文件夹返回明确错误，绝不级联删除案件。
- 归档弹窗改为选择未分类/已有文件夹，并支持直接新建。
- 侧栏归档标题旁提供管理入口；文件夹使用稳定 ID。
- 归档根、文件夹和回收站的展开状态保存在本机 localStorage，异常不影响应用。

## 3. 自动收纳标签逐组收展

- 大分支按“案件 + 父对象 + 完整关系名称 + 目标对象类型”生成稳定 branch key。
- 折叠时保留聚合虚拟节点“关系名称 · N项”，点击可展开该组。
- 展开后不再显示独立漂浮“收起”按钮；真实母节点内部显示下一步动作“收起 N项”，直接点击母节点即可收起其自动聚合分支。
- 母节点点击仍会选中该节点；如果同一母节点有多个大分支，则一次全部展开或全部收起。Option 拖动结束不会误触收展。
- 有自动聚合分支的母节点提供 button/aria-expanded/键盘 Enter、Space 语义；普通节点不受影响。
- 各母节点互不影响；顶部保留全部展开/全部折叠。
- 收展状态按案件保存在 localStorage，并校验版本和有效 key。
- 搜索/筛选命中的折叠对象临时显示，清除筛选后恢复原折叠状态。
- 普通节点选中、关系单击/双击编辑不变。
