# 项目真相库

本目录是“线索研判懒人工作台”的唯一设计事实源，独立于 Obsidian 和 ClueProbe，不读取、不写入、不依赖它们。

## 使用规则

1. 每次确定产品范围、交互、数据模型、技术选型或模块边界，都要先更新对应 Markdown。
2. 每次推翻或调整旧结论，要在 `03-决策记录.md` 写明“为什么改、替代了什么、影响哪些模块”。
3. 每次实现功能前，先检查本目录；实现后更新模块状态与变更日志。
4. 文档不写愿景口号，只写当前已经确定的事实、未决问题和可验证的下一步。
5. 所有模块都要能从本目录回答：它做什么、不做什么、输入输出是什么、依赖谁、如何修改。
