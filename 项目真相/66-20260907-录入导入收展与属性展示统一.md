# 66 - 2026-09-07 录入导入收展与属性展示统一

## 1. 用户反馈

- 添加关联线索字段重复，关系、扩散方式、备注和属性缺少统一层级。
- 批量导入两模式需要统一尺寸，命名为简要录入/全量粘贴。
- 聚合分支展开/收起必须始终点击同一个母标签控件。
- 结构化属性已入库但日常图谱、关系链和详情中不易发现。

## 2. 统一信息架构

### 简要录入

统一680px容器，固定header/footer和滚动内容区：

1. 句式摘要：当前对象 — 关系 → 新对象类型。
2. 关联对象：类型、一个或多个值。
3. 关系：单一可编辑关系输入 + 常用预设，取消输入/下拉/推荐三套并列。
4. 补充信息：按关系显示结构化属性、扩散方式、统一“备注 / 研判说明”。

常用关系：关联、好友、加入群、群成员、同机、绑定手机号、登录IP、使用设备、自定义。用户选择后仍可编辑。

### 全量粘贴

与简要录入同尺寸。内部保留“简要名单/智能表格”模式；智能表格按来源、模板、粘贴、摘要、映射/错误、确认排列。导入记录默认折叠。

扩散方式与关系配置抽成共享定义，统一拼写与默认值。

## 3. 聚合标签

不再使用“折叠时点虚拟节点、展开后点母节点”两种不同控件。每个自动聚合分支始终保留一个固定branch toggle胶囊：

`关系名 · N   +/−`

- 位置锚定母节点关系出口；
- 同一控件展开和收起；
- 点击只切换对应branchKey，不触发节点选择或关系编辑；
- 母节点恢复只负责选择；
- 支持aria-expanded、Enter/Space、全部展开/折叠、持久化和筛选穿透。

## 4. 属性展示

- 节点卡只显示最多2个高价值摘要，不堆全部字段。
- 群：群名称、成员数、最后消息；QQ：昵称、状态/注册地。
- 关系默认仍显示关系名称；选择/关系表最多补2项关键属性：好友=分组/备注，加入群=角色，同机=相似度，绑定手机号=手机号类型。
- 单击关系后右侧显示关系详情和结构化属性；双击仍进入编辑。
- 属性字段显示中文名称并过滤空值。

## 5. 真机验证与发现

- 简要录入弹窗实际显示句式摘要、对象组、单一关系组、常用关系和补充信息。
- 全量粘贴弹窗与简要录入尺寸接近，导入记录折叠，footer固定。
- 群列表真机识别为高置信、3有效0错误、4对象3关系、9对象属性5关系属性。
