# 回归验证策略与当前覆盖

## 原则

每次功能修改不只看“能否编译”，而按四层验证：

1. **结构**：TypeScript 与 Rust 构建；
2. **数据**：SQLite schema、对象数量、关系数量、去重与引用完整性；
3. **工作台**：路径、关系网、表格、当前对象和关联录入是否指向同一案件；
4. **交付**：正式 macOS app 能启动，签名和 DMG 校验通过。

## 当前未完成的真实案例验证

目前没有用户提供的真实案件或脱敏导出，因此不能把回归样本称为“真实案件验证”。它是按已描述的真实结构构造的脱敏回归样本。

在你提供一份可导入的脱敏案件包、CSV 或节点/关系表后，必须补做：

1. 导入前后节点、关系、备注数量一致；
2. 同手机多 QQ、群聊多主体、共同 IP/设备回连不丢边；
3. 图路径、关系网、全量表、简报和导出 SVG 数量一致；
4. 新增关系、撤销、重做、重启恢复完整；
5. 1000 节点 / 2000 关系性能基准。
