# 截图问题回归与路径降噪

> 版本：0.6.4。基于用户提供的新建、添加线索和多跳路径截图回归。

## 截图确认的问题

1. **新建输入会跳转**：全局 A/E 快捷键在 input/textarea/select 中仍生效；输入英文 `a` 或 `e` 会打开“添加线索”或“编辑对象”，表现为输入焦点突然跳走。
2. **添加线索语义不对**：界面前台展示“怎么拓展”，但对普通已有对象添加线索而言，用户首先需要的是“账号类型 + 关联标签”；扩散方式是补充证据语义，不是每次必填的主决策。
3. **多跳图线团与裁切**：旧画布保留上次案件的缩放/平移状态；高连接分支即使折叠，也把聚合关系标签绘在边上，产生文字叠加；部分“有后续关联”的叶子被排除出收束条件，导致手机号→QQ分支未充分聚合。
4. **顶部操作换行**：头部工具组在窄宽空间可收缩，中文按钮按字换行，截图中显示成竖排碎字。

## 修复

### 新建 / 输入稳定性

- 全局快捷键检测焦点：input、textarea、select、contenteditable 内不响应 A/E；
- 新建案件仍使用独立受控表单和 ref 聚焦；不会再从输入字符触发全局编辑动作。

### 添加线索

默认区：

- 线索值；
- 账号类型按钮；
- **关联标签**，按类型自动填充且可直接改名。

可选区：

- 扩散方式；
- 自定义对象类型；
- 推导说明。

这样“要连什么、叫做什么”保持直观，低频取证细节不挡住录入。

### 多跳路径

- 进入/切换案件一律从 100%、原点、收束状态开始；不继承上个案件的画布位置；
- 对高连接同类关系按“父节点 + 标签 + 类型”收束；即使该组部分节点继续向下，也会折叠其余纯叶子；
- 路径视图每组只保留一个代表对象和一个聚合对象；
- 聚合对象写明关系和数量，边不再绘制重复长标签；
- 高连接边不绘制关系文字，去除线团上重叠的“手机号关联QQ号”等文本；
- 顶部工具设置不换行，避免中文按钮变成竖排碎字。
