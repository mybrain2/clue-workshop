# 67 - 2026-09-07 聚合关系标签与批量导入最终修正

## 1. 用户反馈

- 聚合控件“关联QQ号18”像异常实体节点，关系文本、数量和展开图标挤在一起，未沿用原关系标签语法。
- 批量导入中简要名单/智能表格虽然改名过，但模式内容错位，选中简要模式仍显示模板和表头；窗口结构混乱。
- 要求每次修改必须以真实窗口为准，不得仅凭构建通过。

## 2. 聚合关系控件

聚合分支使用固定的branch toggle胶囊，锚定母节点关系出口：

- 关系文本、数量徽标和展开/收起图标分区显示；不再拼成“关联QQ号18”。
- 使用现有edge-label白底、灰边、10px文字，不使用实体节点色框或大阴影。
- 收起和展开始终点击同一个控件、同一位置；点击只切换branchKey，不选中母节点、不编辑关系。
- 多分支有独立垂直偏移，保持母节点和第一子节点间距。
- 保留全部展开/折叠、状态持久化、筛选穿透和键盘操作。

真机截图确认：聚合控件已成为扁平关系标签，文本、数量、符号分离，不再伪装实体节点或遮挡节点。

## 3. 批量导入弹窗

标题保留“批量导入关联”，两个模式严格为：

### 简要录入

只显示：

- 对象类型 + 关系名称；
- 扩散方式；
- 多值名单；
- 备注；
- 候选统计；
- footer“添加 N 条”。

不显示模板、表头、智能映射。

### 全量粘贴

只显示：

- 读取Excel/CSV、剪贴板、截图；
- 模板 + 表头；
- 大粘贴区；
- 有内容时的智能识别摘要；
- 字段映射/错误行；
- 折叠导入记录；
- footer“确认导入 N 行”。

不显示简要对象类型、扩散方式、候选统计。两模式共用相同宽度和最小内容高度，切换窗口不跳。

真机验收确认：简要录入不再出现模板/表头；全量粘贴不再出现简要字段；模式名与选中态正确。
