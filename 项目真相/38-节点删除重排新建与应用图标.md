# 节点删除、有限重排、新建案件与应用图标

> 版本：0.7.4。状态：已实现、回归与发布验证完成。

## 截图问题定位

### 附注文本格式

截图中的“活跃位置”/“机房信息”文字出现错误位置、过大和与主节点重叠，根因是附注卡与相邻主节点共享了过小的垂直行距，且附注空间未参与主图布局。

修复：

- 主线节点行距统一为 144px；
- 主节点下方预留最多两张附注卡空间；
- 附注保持来源节点同宽、30px 高、正下方贴附；
- 来源节点纵向微调时，附注随来源节点一起移动；
- 附注不能独立拖动，避免从属关系失真。

## 节点删除与有限重排

节点即用户所说的“标签”。

- 选中非主体节点后，按 `Backspace` 或 `Delete` 删除；
- 节点右键菜单新增“删除对象”；
- 删除会同时删除该对象参与的关系；
- 删除前保存案件快照，可通过“撤销”恢复；
- 主体簇不能删除；
- 左键拖动节点只能在本层上下微调，范围限制为 ±96px、12px 网格吸附；
- 微调位置按案件保存到本机，关联的附注卡随来源节点一起移动。

这是受限拖拽而非自由画布：保留关系方向和层级，避免用户一拖又把图拖回线团。

## 新建案件

- 第一条线索为空时不预设/高亮任何类型；
- 自动识别到微信、QQ、手机号或 IP 后才高亮对应类型；
- 识别不到时可手动选择；
- 创建按钮只有在案件名、第一条线索和类型均确定时可用。

这修复了空输入状态却显示 IP 高亮的误导。

## 图标

从现有左上角关系图标生成标准 macOS `icon.icns` 并写入 bundle 配置。发布 `.app` 已确认包含图标资源。
