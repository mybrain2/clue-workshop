# 桌面工作台等价迁移实现

## 本轮目的

纠正桌面版只有基础设施、没有核心工作台的问题。网页 `demo/index.html` 的关键调查流作为迁移基线：案件 → 种子线索 → 对象关系 → 路径/关系网/表格 → 当前对象编辑 → 导出。

## 已迁移

### 真实数据

- Tauri commands 不再只返回案件列表；新增按案件读取 `CaseDetail`，包含根节点、实体和关系。
- SQLite 实体字段：类型、值、状态、角色、备注、重点色、重点标记、自定义类型。
- SQLite 关系字段：源、目标、名称、扩散方式、状态、推导备注、强调标记。
- 旧数据库首次打开时会补足样例案件的 13 个实体和 11 条真实关系，用于验证迁移链路。

### 真实工作台

- 中间画布不再使用固定示意节点，读取当前 SQLite 案件实体/关系。
- 调查路径：从根节点按有向关系分层。
- 主体关系网：选中对象的一跳显示；可展开两跳。
- 全量关系表：与画布同源，点击对象可回到当前对象上下文。
- 右侧当前对象不再固定为 `主体 A`；选中任意节点后同步更新类型、角色、状态、备注和关联链。

### 录入与编辑

- 新建案件恢复背景 + 起点类型 + 起点值，在同一 SQLite 事务中创建主体簇、种子对象和初始关系。
- 预设对象类型：微信、QQ、手机号、IP、活跃位置、机房、设备、群聊、平台账号、组织、主体簇、自定义对象。
- 批量值支持换行、英文逗号、中文逗号；同案件内按类型+值去重复用实体，同源同目标同关系不重复建边。
- 对象详情支持状态、角色、备注、重点颜色、重点标记。
- 关系详情支持状态、扩散方式、推导说明和强调线。

### 导出

- 导出从实际 SQLite 案件图读取对象和关系，不再写死 `wxid_lyra` 示例图。
- 生成：
  - `案件简报.md`：基于当前案件对象/关系数量和根节点；
  - `关系脑图.svg`：按当前案件实体生成；
  - `全量关系.csv`：同源关系表。

## 本轮验证

- TypeScript + Vite 构建通过。
- Rust + SQLite `cargo check` 通过。
- 正式 Tauri app bundle 构建通过。
- 运行后数据库实测：`case-demo-01` 有 13 个实体、11 条关系；包含手机号、QQ、IP、设备、群聊、活跃位置、机房等对象。
- 输出：`app/release/macOS/线索研判-0.2.0.app` 与 `线索研判-0.2.0.dmg`。

## 仍未完成，不伪称完成

- SVG 当前为真实节点数据的基础布局，尚未等价网页的标签碰撞避让、聚合节点、拖动、缩放、阅读/总览持久化。
- 撤销/重做与历史快照 UI 尚未迁移。
- 导出尚未包含 PNG、XLSX、casepack 和真正可折叠的 HTML/XMind 图。
- 关系网两跳布局目前为基础布局，尚未达到网页的最终视觉细节。

这些是下一轮必须继续迁移的项目；当前 0.2.0 是“核心真实数据与工作台迁移预览”，仍不是最终 P0。
