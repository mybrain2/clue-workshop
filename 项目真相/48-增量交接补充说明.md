## 2. 交互合同：以本文为准

以下为当前生效规则，替代旧版“按下即拖动”的写法：

| 操作 | 行为 |
| --- | --- |
| 点击节点 | 直接 `onSelect`，显示蓝色主焦点、绿色一跳次焦点、相关边加粗 |
| 点击连线 | 只选中该关系并高亮两端，不打开弹窗 |
| 双击连线 | 打开关系编辑 |
| Option（⌥）+ 拖动节点 | 有限纵向微调，范围 ±96px，12px 吸附 |
| 普通拖动节点 | 不启动拖动，只作为选中操作 |
| 空白处左键 | 平移画布 |
| 滚轮 | 仅缩放，使用原生 `passive:false` 监听器 |
| 非选中节点/连线 | 保持正常颜色与可点击，不做弱化或灰化 |

关键坑已出现两次，必须记住：**改动节点 pointer down 拖动逻辑时，必须同时确认普通点击仍有 `onSelect` 调用**。0.7.12 的故障正是因为保留了 Option 拖动、却把普通点击回调改成了 `undefined`。

## 3. 稳定性与兜底

- 根渲染入口 `src/main.tsx` 已加入 `DesktopErrorBoundary`。
- 渲染异常不再白屏，而是显示“当前数据没有被修改”的恢复页与“重新加载界面”按钮。
- 节点拖动状态在指针结束或取消时统一清理。
- SVG 指针捕获用 `try/catch` 包裹，捕获失败会安全取消拖动状态。
- 图谱滚轮、平移、节点微调三者事件完全分离。

## 4. 发布与目录规则

当前发布目录只保留当前版本，不允许存在历史版本：

```text
app/release/macOS/
├── 线索研判-0.7.12.app
├── 线索研判-0.7.12.dmg
├── 新电脑安装与AI部署说明.md
├── 线索研判_简要操作手册.png
├── 线索研判_简要操作手册.svg
└── automation-0.7.12/
```

发布规则：

1. 版本号必须同时改 `app/package.json` 和 `app/src-tauri/tauri.conf.json`。
2. 必须从本次 `src-tauri/target/release/bundle/macos/线索研判.app` 复制，不得复用旧 bundle 改号。
3. 自动化包中的 MCP JSON 路径要重写为本机实际路径；交付给新机器时使用占位路径并说明替换。
4. 签名、DMG 校验、发布 App 启动必须实际执行，不能只输出构建成功。
5. 每次发布只保留当前版本，历史 App/DMG/automation/QA 截图应删除。

## 5. 新电脑最小交付边界

交付给主体机器只给：

```text
线索研判-<版本>.dmg
新电脑安装与AI部署说明.md
线索研判_简要操作手册.png / .svg
```

主体明确需要自动化时，才给 `automation-<版本>/`。

**不交付**：`项目真相/`、开发 README、源码 `src/`、`src-tauri/`、历史版本、QA 截图、`casework.sqlite3`、其他人案件包或任何案件数据。

新主体案件默认创建在自己的：

```text
~/Library/Application Support/线索研判数据/
```

单案件迁移用“导出案件包 → 打开案件包”；整库迁移仅在主体明确授权时可复制该目录。
