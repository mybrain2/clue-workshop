# 54 - 2026-09-04 成熟 macOS 设计参考与看板壳层

## 1. 用户视觉要求

- 不接受 AI 模板感、通用白卡、等权元数据和凭主观想象的“极简”。
- 简单指操作路径简单，不代表信息贫乏；作为信息看板，身份、分类、原始值、状态、角色、重点、关系和证据仍需清楚存在。
- 审美基准必须来自成熟 Apple 平台产品与公开优秀项目；视觉资源必须与现有功能、布局和交互稳定融合。

## 2. 设计能力与安全

- `mobile-ios-design`：来自公开高使用量技能仓库，安全审查结果 SAFE，已加载；采用 Apple HIG 的 Clarity、Deference、Depth、语义色和系统层级原则。
- `Design System`：SAFE，继续使用 token-first 与语义 token 方法。
- 其他存在自修改、遥测或不固定供应链依赖的设计技能未加载。

## 3. 成熟产品参考

- GitButler：三栏工作台、关系/分支信息密度、检查器结构。
- NetNewsWire：原生侧栏和高密度列表，不以卡片包裹所有内容。
- Apple Freeform：画布、选择环、连线和检查器分工。
- Raycast：紧凑命令与次级动作，不用于承载主工作区。
- Craft / Linear：排版节奏、低噪声状态表达。

调研文件：`成熟 macOS/iOS 风格桌面应用调研：线索研判界面迁移`。

## 4. 当前呈现层切片

本轮只调整呈现层，不改变事件、数据、图谱坐标和关系：

- 左侧案件列表改为原生 sidebar 密度；选中行使用 system blue 低透明度背景，默认无边框。
- 右侧 inspector 改为连续检查器表面，分组通过 inset separator 和 section heading 分隔，减少大白卡套卡。
- 快捷录入改为紧凑两列信息行，主标题与副标题保留但降噪。
- 顶部工具栏统一 ghost / segmented 层级。
- 图谱节点只做表面克制，不删除身份、分类、原始值、状态、角色和重点，也不改变类型色、选中、一跳、状态和重点语义。
