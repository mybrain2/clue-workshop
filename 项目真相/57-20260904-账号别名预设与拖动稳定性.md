## 2. 点击与 Option 拖动崩溃根因

高风险来源：

- `pointermove` 的 React 状态更新闭包读取可被 `pointerup/cancel` 清空的 `drag.current!`，会抛出 TypeError 并触发整页错误边界。
- pointer capture 设置与结束监听不完整，视图刷新、过滤、切案或窗口失焦可能留下陈旧拖动状态。
- 图谱 localStorage 写入没有异常保护，WebView 存储异常会进入错误边界。
- 旧数据可能缺少 accent，直接 `.trim()` 可触发渲染异常。

## 3. 修复

- pointer move 使用不可变快照，不再在异步 updater 中读取 `drag.current!`。
- 拖动记录 pointerId 与 caseId，补齐 lostpointercapture、pointercancel、window blur、视图/案件变化和卸载清理。
- 结束拖动时安全释放 pointer capture。
- nodeOffsets 延迟写入 localStorage，所有读写捕获异常；失败保留内存状态，不导致整页崩溃。
- offset、pan、zoom 与 SVG transform 增加 finite 数值防护。
- accent 使用 `(entity.accent || '').trim()`。
- detail 更新后清理失效的右键菜单；编辑实体/关系弹窗仅在目标仍存在时渲染。
- 保留原合同：普通点击选中；只有 Option 拖动节点；±96px、12px 吸附；空白拖动平移；滚轮缩放。
