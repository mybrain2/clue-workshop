# 附属证据卡与归档文件夹

> 版本：0.7.1。状态：已实现、构建和发布验证完成。

## 位置 / 机房的视觉修正

0.7.0 把活跃位置和机房从主线下沉为背景说明轨道，但截图暴露了一个新问题：背景卡仍被统一堆到画布最下方，造成跨屏长线与大面积空白，反而比主线更抢眼。

本版改为**附属证据卡**：

- 位置、机房保持真实对象与真实关系；
- 卡片缩为 142×38，显示“活跃位置 / 机房信息 + 值”；
- 紧贴其来源账号或 IP 下方，以短虚线相连；
- 不使用箭头、不绘制边上关系标签；
- 多条背景证据在来源对象下依次堆叠。

这使位置/机房能回答“该账号在哪里活跃 / 该 IP 属于哪里”，但不再伪装成能从账号推导出另一账号的同级主线。

## 高频一键关联

主操作区入口改为：

- 关联 QQ；
- 关联微信；
- 关联手机号；
- 关联 IP；
- 更多类型（设备、群聊、位置、组织）；
- 批量导入。

点击高频入口后，录入窗口直接展示预置的关系类型和关联标签，不再首先显示一排类型按钮。需要变更类型、扩散方式、备注或自定义类型时，打开“更换类型、扩散方式与备注”补充区即可。

## 归档

归档不再只是不可见状态：

- 左侧显示为一个有数量的“归档”文件夹；
- 默认收起，可点击展开/收起；
- 归档案件右键菜单提供“修改归档名”；
- 修改沿用已有归档元数据，不会改变案件实体/关系。

回收站采用相同可收起分组形式。
